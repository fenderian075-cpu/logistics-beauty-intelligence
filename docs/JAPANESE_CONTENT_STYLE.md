# 日本語コンテンツ表記ルール

本ポータルは日本語を正本とする。Daily / Weekly / Monthly、EC予定、構造化シグナル、Codex handoff の人間向け本文に以下を適用する。

## 日本由来の名称は自然な日本語を優先

英語ソースに英語表記されていても、日本の祝日・慣用名称・日本企業・日本政府機関・日本の制度名は、一般的な日本語正式名称または定着した日本語表記へ正規化する。

例:
- Obon → お盆
- Idemitsu → 出光興産
- Shiseido → 資生堂
- Japan Customs → 税関 / 財務省税関（文脈に応じる）
- Japan Post → 日本郵便
- Japan Meteorological Agency / JMA → 気象庁
- Japan–Indonesia EPA → 日インドネシアEPA
- Saudi crude → サウジアラビア産原油

日本企業のブランド名・サービス名について、公式に英字表記が一般的なものは無理に日本語化しない。

## 海外固有名詞は一般的な表記を維持

日本でも英字表記が一般的な企業・サービス・媒体・指数は原則としてそのまま使う。

例: DHL, Maersk, Reuters, Amazon, Qoo10, ZOZOCOSME, WCI, IACI, NACCS。

## 機械的な直訳・日英混在を避ける

`Obon遅延`, `IdemitsuのSaudi crude`, `日Indonesia EPA`, `Japan Customsでは` のような不自然な混在表現を生成しない。文章として自然な日本語に直す。

## 出典名

リンクラベルも、公式な日本語名称が明確な日本組織については日本語にする。URL自体は変更しない。

## 生成時チェック

レポート確定前に本文・見出し・表・出典ラベルを走査し、次を確認する。
1. 日本の祝日・慣用名称が不必要に英語化されていない。
2. 日本企業・政府機関が不必要に英語名になっていない。
3. 日本語文中に英語ソース由来の語順や不自然な和英混在が残っていない。
4. 海外企業・国際指数など、英字表記が自然なものまで過剰に翻訳していない。

このルールは事実内容を変更するためのものではなく、表示名称と日本語文章の正規化だけを目的とする。
